# Благовіст — церковний застосунок

Мобільне PWA для iPhone та Android (через браузер / «Додати на екран Дому»).

Постійний сайт (GitHub Pages): https://ramza107.github.io/3proxy/

Робоча назва зараз — **Благовіст** (раніше «Світло»). Варіанти назв зібрані в `src/brand.ts`.

## Розділи

- **Біблія** — повний канон 66 книг українською (Огієнко), ~31 тис. віршів
- **Радіо** — безкоштовні християнські ефіри (Світле, Дзвони, Марія, Світанок…)
- **Календар** — церковні свята й пости
- **Дітям** — історії, уроки, квізи (частина в підписці Благовіст+)
- **Крамниця** — курси, підписка, пожертви (демо-кошик)

## Запуск

```bash
cd church-app
npm install
npm run dev
```

Збірка:

```bash
npm run build
npm run preview
```

## Постійний сайт (Netlify)

1. Зберіть `npm run build` і задеплойте на Netlify (або закріпіть Drop-сайт через Claim).
2. Для автодеплою з GitHub додайте секрети репозиторію:
   - `NETLIFY_AUTH_TOKEN`
   - `NETLIFY_SITE_ID`
3. Workflow: `.github/workflows/deploy-netlify.yml`


## Ліцензія тексту Біблії

Текст у `public/scripture/` зібрано з USFM-джерела перекладу І. Огієнка. Перед комерційним релізом узгодьте права з Українським Біблійним Товариством / правовласником обраного перекладу.

Папку названо `scripture`, а не `bible`, щоб маршрут `/bible` у застосунку не конфліктував із статичними файлами на GitHub Pages.

## Summary for Google reviewers

- App name: **Wahrly**
- Scopes requested:

  - `https://www.googleapis.com/auth/userinfo.email` (connected-account label)
- **No Gmail scopes** — Wahrly does not read mail

- Tokens stored on API server; user can disconnect in Settings
